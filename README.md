# Language Learning Desktop (Windows) App using Flutter

An exercise in Flutter for a basic flashcard app that lets me revise French vocabulary.
This repository contains a Flutter project (`learn_french`) with a (`lib`) that contains main function, home page and flash card layout.

## Quick overview
- Database: CSV (`dico.csv`)
- Templates/ Models: (`lib`) (example: `main.dart`, `flashCard.dart`, `myHomePage.dart`)

## Requirements
- Windows 10 and above
- Flutter SDK used to creating the project

## Clone repository and Run
1. Clone this repository locally.
2. Open your preferred IDE (I used VSCode). 
3. Change directory to learn_french.
``` 
cd learn_french
```
4. Run the app and choose your preferred platform (Windows, Chrome, Edge).
``` 
flutter run lib/main.dart
```
## Project Structure
- `lib` - Dart models
- `assets` - data files
